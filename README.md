# PriceRadar РФ — Сервис мониторинга и кросс-поиска цен маркетплейсов

**PriceRadar РФ** — это веб-платформа и сервис аналитики, позволяющий в один клик сравнить стоимость товара на всех ключевых российских маркетплейсах (**Ozon, Wildberries, Яндекс Маркет, AliExpress Россия, Мегамаркет**), выявить минимальную цену с учетом персональных скидок покупателя и получать мгновенные сигналы в Telegram при падении цены.

---

## 🎯 Ключевые возможности

1. **Анализ ссылки из любого магазина**:
   - Пользователь вставляет URL-ссылку на товар с любого маркетплейса (например, Wildberries или Ozon).
   - Парсер определяет площадку, извлекает SKU, модель, бренд, фото и текущую стоимость.
2. **Интеллектуальный кросс-поиск**:
   - По характеристикам и артикулу сервис находит идентичный товар на остальных маркетплейсах.
   - Сравнительная матрица мгновенно подсвечивает магазин с **самой низкой ценой** и размер экономии.
3. **Учет персональных скидок покупателя**:
   - Поддержка скидки Ozon Карты (до 10-12%), СПП (скидки постоянного покупателя Wildberries до 27%), бонусов Яндекс Плюса и монет AliExpress.
4. **Мониторинг и активация отслеживания**:
   - Если текущая цена не устраивает, покупатель задает желаемый порог (или отслеживает любое снижение) и включает мониторинг.
5. **Сигналы в Telegram-бот**:
   - При фиксации снижения цены робот мгновенно отправляет уведомление в Telegram с указанием:
     - Маркетплейса, где снизилась цена;
     - Прежней и новой стоимости;
     - Разницы в рублях (₽) и в процентах (%);
     - Прямой ссылки на покупку по лучшей цене.
6. **Три тарифных плана**:
   - **Бесплатный**: 1 товар на отслеживании, частота проверки каждые 6 часов, Telegram-сигналы.
   - **Базовый (490 ₽/мес)**: до 5 товаров, проверка каждые 30 минут, персональные скидки, история цен 30 дней.
   - **Премиум (990 ₽/мес)**: до 10 товаров, опрос каждые 5 минут (Flash-проверка), приоритетный парсинг, полная история цен.

## 🛡️ Безопасность аккаунтов (Анализ ведущего инженера)

> **Критический аспект безопасности**: Пользователи вводят данные для применения своих персональных скидок. Как обеспечить 100% защиту?

### Почему запрашивать логин и пароль напрямую — фатальная ошибка?
1. **Финансовые риски**: К Ozon ID привязан Ozon Банк, к Wildberries — WB Кошелек. Хранение паролей в базе данных сервиса подвергает риску реальные деньги пользователей в случае любой компрометации.
2. **Блокировка аккаунтов антифродом**: У российских ритейлеров нет статических паролей (авторизация идет через SMS / Push). Если бэкенд попытается авторизоваться с IP дата-центра, антифрод маркетплейса заморозит личный кабинет пользователя за "подозрительную активность".

### Реализованная архитектура защиты (3 уровня):
- **Уровень 1: Browser Extension Bridge (Рекомендуемый)**:
  - Пользователь использует легковесный плагин для браузера. Плагин считывает итоговую персональную цену со страницы корзины локально на компьютере пользователя. **Никакие пароли, токены или SMS не покидают браузер**.
- **Уровень 2: AES-256-GCM Token Vault**:
  - При необходимости круглосуточного серверного мониторинга принимаются только read-only session cookies (`__Secure-access-token`), зашифрованные на стороне клиента мастер-ключом. Исполнение происходит в изолированных контейнерных песочницах через московские резидентные прокси.
- **Уровень 3: Профиль персональных скидок**:
  - Возможность указать размер скидки (например, СПП 15% и Ozon Карта) без передачи каких-либо авторизационных данных. Сервис математически рассчитывает точные цены.

## 🏗️ Архитектура и стек технологий

```
PriceRadar РФ
├── Frontend: React 19 + TypeScript + Vite + Tailwind CSS 4 + Lucide Icons + Motion
├── Backend API: Node.js + Express (Full-Stack сервер)
├── Парсер-ядро: Детекция SKU, нормализация названий, кросс-поиск аналогов
├── Telegram Dispatcher: Интеграция с Telegram Bot API (Markdown v2, inline-кнопки)
└── Vault: Модель безопасного изолированного хранения сессий
```

### Поддерживаемые маркетплейсы:
| Маркетплейс | Особенности парсинга | Персональная программа лояльности |
|---|---|---|
| **Wildberries** | Mobile Gateway API, учет региона ПВЗ | СПП (до 27%) + WB Кошелек |
| **Ozon** | Kasada WAF, обход TLS Fingerprint | Ozon Карта & Ozon Premium |
| **Яндекс Маркет** | Client-Side Hydration React | Подписка Яндекс Плюс, Сплит |
| **AliExpress** | Разделение СНГ и Global | Купоны продавцов, Монеты |
| **Мегамаркет** | Расчет бонусов СберСпасибо | СберПрайм кешбэк |

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Dev Server на порту 3000)
```bash
npm run dev
```
Сервис станет доступен по адресу `http://localhost:3000`.

### 3. Сборка для продакшена
```bash
npm run build
npm start
```

## 🤖 Настройка Telegram-бота для сигналов

1. Откройте Telegram и перейдите к [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`, задайте имя и юзернейм (например, `MyPriceWatcher_bot`).
3. Скопируйте выданный **HTTP API Token** и вставьте его во вкладку **«Telegram-бот»** в приложении.
4. Отправьте боту [@userinfobot](https://t.me/userinfobot) сообщение, чтобы узнать свой **Chat ID**.
5. Нажмите **«Сохранить настройки»** и протестируйте доставку кнопкой **«Отправить тестовый сигнал»**.

## 💡 Идеи развития и масштабирования (Roadmap от Senior Dev)

1. **ML-детектор накрутки цен**: Алгоритм выявления фальшивых скидок перед распродажами (11.11, Новый год).
2. **Очередь задач Highload**: Использование BullMQ + Redis для параллельного мониторинга 100 000+ товаров.
3. **Геолокационный оптимизатор**: Автоматический подбор ближайшего ПВЗ с наименьшей итоговой ценой.
4. **Автоматический выкуп (Sniping)**: Интеграция быстрого оформления заказа при достижении рекордной скидки.
